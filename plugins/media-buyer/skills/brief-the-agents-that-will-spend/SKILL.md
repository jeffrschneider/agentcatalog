# Brief the agents that will spend

## What it does

Opens a run by telling every agent that will spend the same thing at
once: what the plan is, what each of them owes against it, and by when.

## Where it happens

The agent does this in three activities across four reference processes.
Each one names the activity as that process words it.

- **Brief the Build**
  - `ref/mkt/target-audience-segment`, activity 7 -
    [Build Target Audience Segment](../../../../processes/marketing/target-audience-segment.md)
- **Brief the Department**
  - `ref/mkt/annual-marketing-plan`, activity 15 -
    [Build Annual Marketing Plan](../../../../processes/marketing/annual-marketing-plan.md)
  - `ref/mkt/quarterly-business-review`, activity 15 -
    [Conduct Quarterly Business Review](../../../../processes/marketing/quarterly-business-review.md)
- **Hand the Plan to the Buying Agents**
  - `ref/mkt/media-plan`, activity 13 -
    [Develop Media Plan](../../../../processes/marketing/media-plan.md)

## What to record

Every campaign configuration at a version, every budget move with the
number, the direction, and the reason, and the stop record when the buy
comes off.

That contract covers every activity this abstract agent takes on, and it
is repeated in `com.agentcatalog.agent/RECORDS.md`. What the abstract
agent does not do is in `com.agentcatalog.agent/NOT.md`.
