# Build the campaigns in the platforms

## What it does

Builds the buy in the systems that will run it: campaigns, ad sets and
ads named to the plan line they answer to, the audiences loaded, the
schedule set, and each piece of creative sized to what its placement
takes.

## Where it happens

The agent does this in seven activities across six reference processes.
Each one names the activity as that process words it.

- **Build the Ad Units**
  - `ref/mkt/traffic-ad-creative`, activity 12 -
    [Traffic Ad Creative](../../../../processes/marketing/traffic-ad-creative.md)
- **Prep the Channels**
  - `ref/mkt/product-launch`, activity 6 -
    [Launch Product](../../../../processes/marketing/product-launch.md)
- **Read the Placement Specifications**
  - `ref/mkt/traffic-ad-creative`, activity 2 -
    [Traffic Ad Creative](../../../../processes/marketing/traffic-ad-creative.md)
- **Set up Each Side's Distribution**
  - `ref/mkt/co-marketing-campaign`, activity 11 -
    [Run Co-Marketing Campaign](../../../../processes/marketing/co-marketing-campaign.md)
- **Set up the Paid Buy**
  - `ref/mkt/account-based-play`, activity 11 -
    [Run Account-Based Play](../../../../processes/marketing/account-based-play.md)
- **Set up the Practical Side**
  - `ref/mkt/social-campaign`, activity 7 -
    [Run Social Media Campaign](../../../../processes/marketing/social-campaign.md)
- **Set up the Sending**
  - `ref/mkt/win-back-campaign`, activity 12 -
    [Run Win-Back Campaign](../../../../processes/marketing/win-back-campaign.md)

## What to record

Every campaign configuration at a version, every budget move with the
number, the direction, and the reason, and the stop record when the buy
comes off.

That contract covers every activity this abstract agent takes on, and it
is repeated in `com.agentcatalog.agent/RECORDS.md`. What the abstract
agent does not do is in `com.agentcatalog.agent/NOT.md`.
