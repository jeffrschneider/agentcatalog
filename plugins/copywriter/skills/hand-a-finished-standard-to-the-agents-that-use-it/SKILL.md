# Hand a finished standard to the agents that use it

## What it does

Once a standard is written, the agent walks the agents that will work
from it through it on a real piece, and records what each of them says
it changes about their own work.

## Where it happens

The agent does this in two activities across two reference processes.
Each one names the activity as that process words it.

- **Brief the Agents that Write to It**
  - `ref/mkt/brand-voice`, activity 17 -
    [Define Brand Voice and Messaging](../../../../processes/marketing/brand-voice.md)
- **Hand over the Persona**
  - `ref/mkt/buyer-persona`, activity 18 -
    [Develop Buyer Persona](../../../../processes/marketing/buyer-persona.md)

## What to record

Every draft at a version, and the DONE records of the patterns it works
inside. A claim it uses cites the register entry it came from.

That contract covers every activity this abstract agent takes on, and it
is repeated in `com.agentcatalog.agent/RECORDS.md`. What the abstract
agent does not do is in `com.agentcatalog.agent/NOT.md`.
