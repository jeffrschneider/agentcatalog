# Set the Parameters

## What happens

The processes that use this activity word it differently:

- in `ref/mkt/display-retargeting`, placements, dates, budget and what a
  result is worth
- in `ref/mkt/influencer-campaign`, markets, platforms, dates, budget
  and deliverables
- in `ref/mkt/landing-page`, the audience, the action asked for, the
  date
- in `ref/mkt/social-campaign`, platforms, audience, dates, budget
- in `ref/mkt/win-back-campaign`, channels, contact limits, dates, and
  the goal

## What to record

The run's plan, the CONVENED and DONE records of everything it convenes,
the launch record naming who said go, and the final report against the
brief.

That contract covers every activity this abstract agent takes on, and it
is repeated in `com.agentcatalog.agent/RECORDS.md`. What the abstract
agent does not do is in `com.agentcatalog.agent/NOT.md`.
