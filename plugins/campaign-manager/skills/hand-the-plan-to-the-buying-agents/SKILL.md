# Hand the Plan to the Buying Agents

## What happens

Every agent that will spend hears the same plan.

## Where it happens

- `ref/mkt/media-plan`, activity 13 -
  [Develop Media Plan](../../../../processes/marketing/media-plan.md)

## What to record

The run's plan, the CONVENED and DONE records of everything it convenes,
the launch record naming who said go, and the final report against the
brief.

That contract covers every activity this abstract agent takes on, and it
is repeated in `com.agentcatalog.agent/RECORDS.md`. What the abstract
agent does not do is in `com.agentcatalog.agent/NOT.md`.
