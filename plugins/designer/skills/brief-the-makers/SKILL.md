# Brief the Makers

## What happens

The processes that use this activity word it differently:

- in `ref/mkt/account-based-play`, every agent hears the same play at
  once
- in `ref/mkt/brand-guidelines`, everyone who writes or draws hears the
  change
- in `ref/mkt/brand-identity`, everyone hears the same request and the
  same dates
- in `ref/mkt/brief-industry-analyst`, every agent hears the same
  request at once
- in `ref/mkt/co-marketing-campaign`, both sides hear the same request
  at the same time
- in `ref/mkt/conversion-experiment`, everyone hears the same request at
  once
- in `ref/mkt/creative-assets`, say what is needed, at what size, and by
  when
- in `ref/mkt/customer-newsletter`, everyone hears the same request at
  once
- in `ref/mkt/enable-channel-partner`, every producing agent hears the
  same request at once
- in `ref/mkt/landing-page`, everyone hears the same request at once
- in `ref/mkt/nurture-sequence`, everyone hears the same request at once
- in `ref/mkt/sales-enablement-kit`, every making agent hears the same
  request at once
- in `ref/mkt/test-ad-creative`, every maker hears the one element under
  test
- in `ref/mkt/win-back-campaign`, everyone hears the offer and the
  segment at once

anything not made from scratch.

That contract covers every activity this abstract agent takes on, and it
is repeated in `com.agentcatalog.agent/RECORDS.md`. What the abstract
agent does not do is in `com.agentcatalog.agent/NOT.md`.
