# Make sure each affected person hears first

## What it does

Before anything is announced to the staff, the agent gives each manager
the message and the list of the people they must tell in person, and
records who was told, by whom and when, so nobody affected learns of a
change from the announcement.

## Where it happens

The agent does this in one activity across one reference process. Each
one names the activity as that process words it.

- **Tell Each Affected Person**
  - `ref/hr/change-the-organization-structure`, activity 14 -
    [Change the Organization Structure](../../../../processes/human-resources/change-the-organization-structure.md)

## What to record

The timeline at a version, saying what was known at each point, who
established it, and who was told. Each audience's wording at the version
that actually went out, with the versions it replaced left where they
are. The CONVENED and DONE records of everything it convenes. The go
record, naming the person who said go and the time they said it. The
report afterwards, setting what happened against what the announcement
or the response was meant to do.

That contract covers every activity this abstract agent takes on, and it
is repeated in `com.agentcatalog.agent/RECORDS.md`. What the abstract
agent does not do is in `com.agentcatalog.agent/NOT.md`.
