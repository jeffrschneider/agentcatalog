# performance-calculator

## set-the-method-and-gather-the-flows

Works with the chief financial officer to write down how returns are
computed before any number exists, then gathers every deal's dated
cash flows and current mark from the books and the approved
valuations.

covers:
- Gather the Cash Flows and Values
- Write Down the Performance Method

## calculate-the-returns

Calculates the internal rate of return (IRR) and the multiples, gross
and net, by deal and by fund for the track record and for each
quarter, and attributes each deal's gain, treating the losses the same
way as the gains.

covers:
- Attribute Each Deal's Gain
- Calculate the Fund's Performance
- Calculate the Track Record

## tie-freeze-and-keep-the-figures

Has each figure traced to the audited statements or the books, freezes
one dated set that every document uses, and keeps the method, the
workpapers and every version sent for as long as the rules require.

covers:
- Freeze the Figures at a Date
- Keep the Records the Rules Require
- Tie the Figures to the Audited Statements
