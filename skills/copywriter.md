# copywriter

## take-in-a-brief

The agent sits in the briefing that starts the work and takes down what
is wanted, who it is for, what has changed and when each piece is due,
so it writes from the same account of the request as everyone else.

covers:
- Brief the Makers
- Brief the Creatives
- Brief the Creators
- Brief the Entry
- Brief the Piece
- Brief the Story
- Brief the Pages in the Cycle
- Brief the Agents that Act
- Brief the Agents that Remake the Material

## hand-a-finished-standard-to-the-agents-that-use-it

Once a standard is written, the agent walks the agents that will work
from it through it on a real piece, and records what each of them says
it changes about their own work.

covers:
- Brief the Agents that Write to It
- Hand over the Persona

## draft-the-options-to-choose-from

The agent writes two or three candidates rather than one, each with the
case for it, so whoever decides has something to choose between.

covers:
- Draft the Candidate Positions
- Draft the Candidate Directions
- Generate the Candidate Names

## settle-on-one-direction

The agent weighs the candidates on the table and settles which one the
writing will be done in, including where two organizations have to agree
on a single concept.

covers:
- Settle on a Direction
- Settle the Joint Direction

## agree-what-the-piece-will-argue

Before writing, the agent settles what the piece argues, in what order,
and the one line everyone will give for it. Getting that agreed first
keeps the argument out of the draft.

covers:
- Agree What the Story Argues
- Agree the Outline
- Settle the Story
- Settle the Explanation
- Settle What the Briefing Will Say
- Settle the Booth Message
- Settle the Message

## write-the-positioning-and-the-messaging

The agent writes the standing message set: the positioning statement,
the promise, the proof points under it, and the pillars in the order
they are meant to be said.

covers:
- Write the Positioning and the Promise
- Write the Messaging
- Build the Messaging Architecture

## write-the-voice-rules-and-the-word-list

The agent sets how the organization sounds, trait by trait, and how that
changes by channel and by situation. It keeps the list of words to use
and words to avoid, including the words customers use for the problem
themselves.

covers:
- Draft the Voice
- Set the Tone for Each Situation
- Set the Voice Rules
- Write the Word List
- Record the Words This Person Uses

## write-the-standards-others-are-scored-against

The agent writes each rule so another agent can apply it without
interpreting it, shows a passing and a failing example under each one,
and scores real work against the draft to see whether the rules hold.

covers:
- Write the Rules
- Write the Usage Rules
- Show the Examples
- Test the Rules on Real Work
- Build out the System

## write-the-version-each-audience-reads

The agent takes one settled message and writes it again in the words
each audience uses, so customers, staff, partners and the press are all
told the same thing in language that fits them.

covers:
- Write the Other Versions
- Tailor for Each Audience
- Write the Version Each Audience Gets
- Produce What Customers and Sellers Read

## write-an-announcement-and-its-press-material

The agent writes the release and the shorter versions of it, and puts
together the facts and the answers a reporter will want. Every quote is
approved by the person it is attributed to before it goes anywhere.

covers:
- Write the Release
- Write the Announcement
- Produce the Pitch Materials
- Make the Press Materials
- Gather the Quotes

## write-the-statement-during-an-incident

The agent writes what the organization says while an incident is still
moving: a short first line while the facts are being confirmed, the full
statement, the note staff read before the press does, and a new version
each time the facts change.

covers:
- Issue a Holding Line
- Draft the Statement
- Notify the Staff
- Update the Response

## write-what-a-seller-says

The agent writes what a person selling actually uses in front of a
buyer: the deck, the leave-behind, the claims and the proof on a card,
the answer to every objection, and the version of all of it a partner or
an account owner needs.

covers:
- Build the Deck
- Write the One-Pager
- Write the Card
- Write the Objection Answers
- Settle the Answers
- Enable Sales
- Make the Sales Material
- Brief the Booth Staff
- Build the Partner Selling Kit
- Produce the Partner Material
- Build the Recruitment Material
- Write What Will Be Said

## write-the-material-for-a-briefing-or-a-board

The agent writes what a small named audience reads before and during a
session, such as the pre-read, the deck, the written answers, and a
paper per decision with its options laid out.

covers:
- Build the Briefing Material
- Write the Decision Papers
- Build the Materials

## write-a-long-piece

The agent writes the full piece to the shape and the length that were
agreed, whether that is an article, a customer story, a newsletter, or
answers written against somebody else's criteria.

covers:
- Write the Draft
- Write the Entry
- Write the Proposal

## edit-a-draft

The agent reads a draft as an editor and says what has to be rewritten,
naming each thing rather than quietly rewriting it.

covers:
- Edit the Draft
- Edit the Change

## rewrite-what-has-to-change

The agent goes back to wording that is already out and changes what no
longer holds: a claim that was corrected, a number that moved, a name
that changed, or a page the numbers say is losing people.

covers:
- Rewrite What Has to Change
- Rewrite What the Words Say
- Fix What the Numbers Show
- Write the Change

## write-ad-copy-inside-each-placement-limit

The agent writes headlines and body that fit inside the character and
size limits each placement sets, produces enough versions to rotate or
to test, and puts in the lines a market requires the ad to carry.

covers:
- Write the Ads
- Write the Text for Each Placement
- Add the Disclosures Each Market Requires
- Make the Ad Set
- Produce the Variants
- Size for Every Channel

## write-the-copy-a-campaign-needs

The agent writes the words for whatever a campaign is putting out, made
to the chosen direction and sized for where each piece will appear.

covers:
- Produce the Assets
- Produce the Content
- Produce the Material
- Produce the Posts
- Produce the Joint Material
- Produce the Promotion Material
- Promote the Conference
- Produce the Invitation and Materials
- Produce the Booth Material
- Make What the Path Needs

## write-a-message-sequence

The agent writes the messages a program sends and the order they go in,
and rewrites the ones the numbers argue against once it is running.

covers:
- Produce the Messages
- Write the Sequence
- Tune the Branches

## write-the-follow-up-after-a-session

The agent writes what goes to people after they attended something: the
recording, the material that was promised, the answers to what was
asked, and what happens next.

covers:
- Follow up with the Members
- Follow up with the People Who Came
- Follow up with the Registrants

## write-an-ask-to-a-named-person

The agent writes the request itself, saying plainly what is being asked
of the reader, what it involves and by when, along with the reminder
that follows it.

covers:
- Write the Ask
- Write the Request
- Invite the Members
- Open the Call for Sessions

## write-the-page-a-visitor-lands-on

The agent writes the page someone arrives at from an ad or an
invitation, so it answers the thing they clicked on and carries them
through to signing up.

covers:
- Ready the Landing Pages
- Open Registration

## write-for-video-and-recordings

The agent writes the words a recording is built on and the words it
leaves behind: the script and its order, the captions timed to the
audio, the transcript, and the written version of a talk that was
already given.

covers:
- Settle the Script
- Write the Captions and Transcript
- Reuse the Talk
