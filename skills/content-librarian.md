# content-librarian

## rebuild-the-inventory

The agent builds the list of everything the organization has published
from what the site and the stores actually serve, recording for each
piece what it was made to do, when it last changed and what it is doing
now.

covers:
- List Where the Brand Appears
- Map the Touchpoints
- Rebuild the Inventory
- Take Stock of What the Department Holds
- Take Stock of the Marks in Use

## pull-a-sample-of-live-material

The agent pulls a sample of what is live, taken as it is actually
served, so another pass can read it and judge it.

covers:
- Draw the Sample
- Read How the Company Sounds Now

## find-everything-that-says-a-thing

The agent searches everything already published for the pages,
templates, assets and sends that carry a particular subject, claim,
price or identity, and hands the list to whoever has to act on it.

covers:
- Check the Library for Overlap
- Find Every Page It Touches
- Find Everything on the Old Identity
- Gather What Is Already Known
- List What the New Version Fails
- Restate the Price Everywhere It Is Published
- Sweep for What Was Missed

## match-published-work-to-the-questions-it-answers

The agent sets what has been published against the questions buyers ask,
says which piece answers which question, names the questions with
nothing behind them, and sends each gap to the agent that can close it.

covers:
- Find the Gaps
- Hand the Gaps to the Owners
- Inventory the Content against the Map

## decide-what-happens-to-each-page

The agent decides for each page or surface whether it is updated, merged
into another, retired, replaced or left alone, and records the reason
behind every decision.

covers:
- Decide What Happens to Each Page
- Decide What Happens to Each Surface

## route-a-change-to-the-right-sign-off

The agent works out whether a requested change is a small edit or needs
a fuller process and who has to sign it, and puts every merge and
retirement in front of a person before anything comes down.

covers:
- Approve the Merges and the Retirements
- Route the Change

## take-in-requests-and-score-them

The agent collects what every agent wants made and scores each candidate
against the goals already set and the evidence behind it.

covers:
- Collect the Topic Candidates
- Score the Candidates

## build-the-schedule

The agent works out which pieces a cycle covers and by when, sets the
order and the due dates, lays the slate out with a format, an agent and
a date on every line, and publishes it where every agent reads it.

covers:
- Draft the Calendar
- Publish the Calendar
- Set the Order and the Dates
- Take in the Signal

## say-what-else-is-due-on-the-same-audience

The agent reads the plan and says what other changes and tests are
already due on the same visitors, so two of them do not land at once.

covers:
- Clear the Traffic

## brief-the-agents-that-do-the-work

The agent opens a cycle by giving every agent that will work on the
material the same account of what is wrong with it and what is changing.

covers:
- Brief the Agents that Remake the Material
- Brief the Pages in the Cycle

## run-the-cutover

The agent runs the changeover to the new material. The properties move
across, the old files come out of the store, and the old version is
closed and recorded.

covers:
- Retire the Old Identity
- Switch the Properties

## place-a-piece-in-the-library

The agent takes a finished recording or piece, gives it an address, and
puts it in the library with the cut and the captions it needs to be
found and used again.

covers:
- Prepare the Recording for Reuse

## report-what-the-cycle-changed

The agent reports what changed over a cycle, what came down, what it
cost and what it moved, with the source under every figure.

covers:
- Report the Cycle
- Report the Transition

## close-out-and-record-what-was-learned

The agent closes a change once the requester agrees it is done, and
records what to repeat and what to avoid next time.

covers:
- Close out the Change
- Record What Was Learned
