# integration-keeper

## name-what-a-tool-must-connect-to

Brings the systems either side into the evaluation of a tool, says what
that tool would have to connect to, and takes the tool once it has been
chosen.

covers:
- Brief the Evaluation
- Map What It Must Connect To
- Take in the Chosen Tool

## agree-the-flows-field-by-field

Names the system on each side with the person who owns it, agrees every
field that moves with its direction, its cadence and what starts the
move, and gets a decision on which side is right where the two owners
disagree.

covers:
- Name the Systems Either Side
- Agree What Flows Where
- Decide Which Side Wins

## prove-a-link-away-from-live

Builds the link where no real record is written, moves a known set and
counts both sides field by field, and breaks the link on purpose to see
what it retries, duplicates, drops and queues. A change to a link
already running is tried the same way.

covers:
- Build the Link away from Live
- Move a Known Set and Compare
- Test What Happens When It Breaks
- Try the Change away from Live

## switch-a-link-on-and-watch-it

Puts the link through the review that has to clear, switches it on with
a written way back, watches the first runs, and reconciles the counts on
both sides afterwards. A difference nobody can explain is never signed
off as rounding.

covers:
- Review the Link before It Is Live
- Switch It On
- Watch the First Runs
- Reconcile the Two Sides

## write-down-what-flows-where

Keeps the record of what flows where at a version, naming the fields it
does not yet cover, so anybody can read what a system is fed and what
reads it without opening the link. Files what the build taught.

covers:
- Write down What Flows Where
- Record What Was Learned

## hand-a-live-link-over-and-keep-checking-it

Hands the running link to whoever administers the tool, with the flow
record, the credentials and the date it is next checked, and reads it
again on that cadence to see it still carries.

covers:
- Hand It to the Administrator
- Check the Links Still Carry

## stop-the-links-when-a-tool-goes

Finds everything that depends on a tool being retired, takes the export
while the tool still runs, and stops each link on the record, saying
what it was carrying and where that now comes from.

covers:
- Find What Depends on It
- Take the Export
- Turn Off the Links
