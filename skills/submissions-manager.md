# submissions-manager

## take-in-an-opportunity

The agent reads what an outside body is asking for, what it recognizes
or covers, when it closes and what it costs, and records that against
the body it came from.

covers:
- Take in the Award
- Take in the Call
- Take in the Request

## read-the-rules-and-the-format

The agent works through the body's eligibility rules, categories, word
limits and required format, and writes down every constraint the
submission has to meet.

covers:
- Read the Entry Rules

## decide-what-to-put-forward

The agent weighs the fee and the effort against what a submission is
worth, and settles what the organization actually enters: which
category, which work, and which named person will speak.

covers:
- Decide Whether to Enter
- Pick the Entry
- Pick the Speaker

## brief-the-agents-that-owe-material

The agent calls the briefing that starts a submission, so every agent
that owes a section, a number or an image hears the same requirements
and the same deadline at once.

covers:
- Brief the Entry

## draft-the-submission

The agent writes the submission to what the body asked for, answering
its criteria in the order and the length the body set.

covers:
- Write the Entry
- Write the Proposal

## file-it-before-the-deadline

The agent files the submission in the body's own format before the
deadline, pays or flags the fee, and confirms the body received it.

covers:
- Submit the Entry
- Submit the Proposal
- File What the Cycle Requires

## answer-what-the-body-asks-next

The agent handles the questions, clarifications and interviews that come
back after a submission is filed, and records every question with the
answer that was given.

covers:
- Answer the Judges

## record-the-decision-and-pass-it-on

The agent chases the decision until it arrives, records it against the
entry whether it won or lost, and passes a result worth announcing to
whoever runs the announcement.

covers:
- Track the Result
- Hand the Result On

## settle-the-terms-and-the-arrangements

Once something is accepted, the agent settles what was agreed with the
body, including recording rights and what the organizer requires by
when, and makes sure the room, the equipment and the travel are covered.

covers:
- Settle the Terms
- Handle the Arrangements

## rehearse-the-talk

The agent runs the talk to time before it is given, and says what falls
flat and has to change.

covers:
- Rehearse the Talk

## report-what-it-produced

The agent writes the account of what the submission produced, including
the audience it reached and what came back from it.

covers:
- Report the Result

## record-what-was-learned

The agent writes down what to repeat and what to avoid next cycle, and
keeps it against the body, so the next submission starts from what the
last one taught.

covers:
- Record What Was Learned
