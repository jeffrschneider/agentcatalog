# editor

## brief-the-piece

The agent opens the work by telling everyone who will write, draw or
promote the same thing at the same time: what is wanted, what is
changing, and when it is due.

covers:
- Brief the Agents that Write to It
- Brief the Department
- Brief the Entry
- Brief the Makers
- Brief the Pages in the Cycle
- Brief the Piece
- Brief the Story

## agree-what-the-piece-argues

Before anything is drafted, the agent settles what the piece argues, the
order its sections come in, and the evidence each section rests on.

covers:
- Agree What the Story Argues
- Agree the Outline
- Settle the Script
- Shape the Talk

## edit-a-draft

The agent reads a draft against what was asked for and says item by item
what has to be rewritten, in terms the writer can work through without
coming back to ask what was meant. It holds the piece at that standard
for as many rounds as it takes.

covers:
- Check It Once
- Edit the Card
- Edit the Change
- Edit the Draft
- Edit the Entry
- Edit the Release
- Edit the Rewrite
- Review the Cut

## test-a-claim-against-its-evidence

The agent checks whether the evidence under a statement carries what the
statement claims, and names the gap where it does not.

covers:
- Test the Positions against the Evidence

## write-the-positioning-and-the-messaging

The agent writes the statement of what the organization or the product
is for, the promise behind it, the proof points under it, and the
version each audience gets.

covers:
- Build the Messaging Architecture
- Write the Messaging
- Write the Positioning and the Promise

## define-the-voice

The agent writes down how the organization sounds: the traits it writes
with, how the tone changes by channel and by situation, and the words to
use, the words to avoid, and the names and spellings it settles on.

covers:
- Draft the Voice
- Set the Tone for Each Situation
- Set the Voice Rules
- Write the Word List

## write-rules-that-can-be-scored

The agent turns a standard into numbered rules written tightly enough
that a scoring agent can apply them, each one with a passing and a
failing example.

covers:
- Turn the Voice into Scorable Rules
- Write the Rules

## read-what-is-already-published

The agent reads a body of live material and says how it reads as a
whole, whether it sounds and looks like one organization, and how it
would fare against rules that have not issued yet.

covers:
- Read How the Company Sounds Now
- Read the Set as a Whole
- Score Old Material against the Draft Rules

## build-a-document-for-an-occasion

The agent writes and assembles the material one session or audience
needs, such as a pre-read, a board pack, a decision paper with its
options, a pitch note, or the notice and the answers that go out with a
change.

covers:
- Build the Materials
- Build the Pack
- Make What the Path Needs
- Produce What Customers and Sellers Read
- Produce the Pitch Materials
- Write the Decision Papers

## rehearse-a-live-delivery

The agent runs a talk or a briefing before the real audience hears it,
asks the hard questions early, runs it to time, and says what has to
change.

covers:
- Rehearse the Briefing
- Rehearse the Talk

## turn-a-talk-into-other-pieces

The agent takes a talk that has been given and works it into the pieces
that outlive it: the clips, the written version, and the slides that get
shared.

covers:
- Reuse the Talk

## rewrite-the-standing-wording

The agent updates the names, boilerplate and descriptions a change has
made wrong, wherever the organization uses them.

covers:
- Rewrite What the Words Say

## plan-the-slate

The agent works out how much work the makers can carry this period and
lays the slate out on a schedule, with a format, an agent and a date
against each piece.

covers:
- Draft the Calendar
- Size the Production Capacity
