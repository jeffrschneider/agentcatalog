# event-manager

## take-in-what-the-event-must-deliver

The agent works out who the event is for, what it has to accomplish and
by when, and records that as the thing the whole run is measured
against.

covers:
- Take in the Audience and Date
- Take in the Conference
- Take in the Cycle
- Take in the Show
- Take in the Topic and Date

## settle-the-shape-of-the-event

The agent settles what kind of event it is, how long it runs, what the
budget and the target are, and what actually happens in it, down to the
sessions and the order they come in.

covers:
- Settle the Format and Program
- Settle the Format and the Presenters
- Set the Conference Plan
- Choose the Program
- Set the Agenda

## turn-the-event-into-a-deadline-list

The agent turns the plan and the organizer's rules into the dated list
every other agent works to, saying what each one owes and when it is
due.

covers:
- List Every Deadline

## settle-the-space-and-the-suppliers

The agent says what space, food, equipment and travel the event needs
and on what dates, and holds the record of what has been committed
against the plan.

covers:
- Book the Venue and Suppliers
- Book the Venue and the Suppliers
- Make the Arrangements

## plan-the-day-and-check-the-site-is-ready

The agent works out the footprint, who is where and what happens minute
by minute, then walks the site before doors open to confirm it matches
the plan.

covers:
- Plan the Presence
- Prepare the Run of Show
- Set up the Venue

## open-the-sign-up

The agent gets the registration live, with the form, the sessions and
the tracking set up so every sign-up is recorded.

covers:
- Open Registration
- Set up the Session in the Platform

## fill-the-room

The agent decides who is invited and how many have to come, sends the
ask, chases and confirms the replies, works the waitlist, and watches
the pace against the target week by week.

covers:
- Build the Invitation List
- Invite the Members
- Invite the Press and the Analysts
- Work the Registration List
- Watch the Registrations

## send-the-material-before-the-session

The agent gets the reading material to the people attending ahead of
time and collects the answers they owe before they arrive.

covers:
- Send the Pre-Read
- Collect the Early Input

## settle-the-pitch-and-brief-the-staff

The agent cuts the story down to what can be said in a short
conversation, and makes sure the people working the floor know the
pitch, the questions to ask and the steps to record a visitor.

covers:
- Settle the Booth Message
- Brief the Booth Staff

## run-the-event-on-the-day

The agent runs the event while it is happening: people are checked in,
the program keeps to time, every visitor is recorded, and the calls that
have to be made on the day get made and written down.

covers:
- Run the Event
- Run the Session
- Run the Show
- Run the Show Days

## follow-up-with-the-people-who-came

After the event the agent sends the promised material to the people who
attended and routes the interested ones to whoever picks them up.

covers:
- Follow up with the People Who Came

## sort-and-route-the-feedback

The agent groups what was said into themes with the quotes behind each
one, and gets every theme to the owner who can act on it.

covers:
- Sort the Feedback
- Route the Feedback

## report-how-the-event-did

The agent writes the account of the event: who came, what it cost, what
it produced, and how that compares with what the event was asked to do.

covers:
- Report How the Event Did
- Report How the Session Did
- Report the Conference
- Report the Show

## record-what-was-learned

The agent writes down what to repeat and what to change next time, and
keeps it where the next run of the same kind of event starts from it.

covers:
- Record What Was Learned

## run-the-request-and-answer-round

The agent runs a round where every function submits what it is asking
for in one format by one date, and then tells each function what it was
given and the rules that come with it.

covers:
- Collect What Each Function Asks For
- Tell Every Function What It Has
