# event-program

## open-the-call-for-sessions

Puts out the call for talks, states what a proposal has to contain and when it is due, and takes in what customers and staff send back.

covers:
- Open the Call for Sessions

## settle-the-program

Decides what the event carries and in what order. It settles the kind of session and how long it runs, picks the talks and the keynotes, puts the questions or the sessions into an order, and says who presents each one.

covers:
- Choose the Program
- Set the Agenda
- Settle the Format and Program
- Settle the Format and the Presenters

## line-up-the-speakers

Asks the people who will speak, confirms each one, and tells them what the session is for and who will be sitting in front of them.

covers:
- Line up the Speakers

## collect-the-speaker-material

Chases every deck, bio, headshot and permission to its deadline, reads each one against what the event requires, and gets the signatures the material needs.

covers:
- Clear the Speaker Material

## build-the-presentation

Builds the slides and the demo for a session so that they follow the agenda that was agreed.

covers:
- Build the Presentation

## run-the-rehearsal

Writes the minute-by-minute plan for the event and runs the rehearsal against it, so that every presenter has connected, used the equipment and run their part before an audience is there.

covers:
- Prepare the Run of Show
- Rehearse the Session

## ready-the-venue

Gets the rooms ready before the doors open, which means the load in, the room dressing and a test of the equipment each session needs.

covers:
- Set up the Venue
