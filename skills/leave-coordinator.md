# leave-coordinator

## take-in-the-request

Takes in a leave request in any form, or an absence that has passed the
policy's point, acknowledges it in writing with the next step and the
rights that apply, checks it against the policy and the local leave
rules, and takes in time away decided on an accommodation request as a
leave request with that decision beside it.

covers:
- Acknowledge the Request
- Check the Request Against the Rules
- Hand Time Away to the Leave Process
- Take in the Request

## keep-health-information-restricted

Asks only for the documents the policy and the rules allow for the kind
of leave, keeps every document with health information in a file only
the named people may open, and passes on from the leave record only the
outcome already approved.

covers:
- Ask for the Documents the Leave Needs
- Keep Health Information Restricted
- Read the Leave Record

## track-the-leave

Tells the manager the dates and nothing about the reason, tracks the
leave and any change tied to a return from it to their dates, checks an
extension or an early return for the approver, plans the return with the
manager, and closes the leave on the record with the dates taken and the
balance left.

covers:
- Close the Leave on the Record
- Decide an Extension or an Early Return
- Plan the Return
- Tell the Manager the Dates
- Track the Leave
- Track the Return Date
