# audience-operator

## take-in-the-change-being-asked-for

The agent sits in the briefing that starts a change and takes down what
is being asked for, what it is for, and which design or plan it builds
to.

covers:
- Brief the Build
- Brief the Cycle
- Brief the Makers

## build-a-list-from-a-rule

The agent runs a selection rule and its exclusions against the contact
database and produces the list, pool or segment it describes, with the
counts checked before anything is used.

covers:
- Build the List
- Build the Contact Set
- Build the Notice Lists
- Build the Audience Pools
- Rebuild the Segments

## apply-consent-and-suppression

The agent takes out everyone the consent record does not cover and
everyone on a suppression list, and writes that exclusion into every
list and system the change touches.

covers:
- Apply Consent and Suppression
- Apply the Suppression

## check-the-suppression-held

After the sending or the serving has run, the agent checks that nobody
who was taken out was reached anyway, and reports what it finds.

covers:
- Check the Suppression Is Holding

## load-an-audience-into-the-systems-that-reach-it

The agent pushes a built audience into the systems that will send to it
or serve to it, with consent and suppression already applied, and
confirms the counts that arrived match what was sent.

covers:
- Load the Audiences the Plan Names

## put-the-fields-in-one-format

The agent rewrites names, addresses, company names and other fields into
a single agreed format, and records the counts before and after.

covers:
- Standardize the Fields

## merge-the-records-that-are-the-same-person

The agent finds records that look like the same person, lists what
disagrees between them, and once the merge is agreed it combines them
into one record keeping the strictest consent.

covers:
- Propose the Merges
- Merge the Records

## fill-missing-fields-from-licensed-sources

The agent fills gaps in the contact data from sources the organization
licenses, and records the source and the date for every field it filled.

covers:
- Fill the Gaps

## take-records-out-of-the-database

The agent lists the records that qualify to come out, such as the
inactive, the undeliverable and the expired, and removes what a person
signed for, keeping a copy that puts the change back.

covers:
- List What Comes Out
- Remove the Records

## build-a-sending-program

The agent assembles a program in the sending system to the approved
design: the steps, the waits, the branch conditions and the exits, at a
version.

covers:
- Build the Program

## test-a-program-before-it-sends

With sending switched off, the agent walks test contacts down every
branch of a program and records what each one did.

covers:
- Run Test Contacts Through It

## turn-a-program-on

Once the named owner says go, the agent starts the program and lets the
segment begin entering it.

covers:
- Turn It On

## change-a-program-that-is-already-running

The agent changes the steps, waits and rules of a running program where
the numbers argue for it, and records what changed and when.

covers:
- Tune the Branches

## put-a-study-into-the-field

The agent sends the invitation or the ask to the sample it was given and
collects what comes back, keeping track of who was approached and who
answered.

covers:
- Field the Study
- Field the Wave
- Invite the Buyers
