# controls-tester

## prepare-the-test

Opens each test from the control list with the control, the period, the
owner and the last result, reads the control as written with the risk it
covers and the evidence it should leave, and walks through one instance
with the control owner to confirm it runs as written.

covers:
- Open the Test
- Read the Control as Written
- Walk Through the Control With Its Owner

## test-the-sample

Draws the sample from the whole period at the size the statistician
agent set, with the population and the draw recorded, tests each item
against the evidence the control should leave, writes up each failure
with its cause, tests each fix again on a new sample, and records what
the test taught.

covers:
- Draw the Sample
- Record What the Test Taught
- Test Each Item Against Its Evidence
- Test the Fix Again
- Write Up Each Failure With Its Cause

## check-duties-stay-separate

Reads every person's access across the finance systems against the list
of duties that must stay separate, flags each person who could both
prepare and approve the same thing, and reads the period's records for
anything one flagged person both prepared and approved.

covers:
- Flag Who Could Both Prepare and Approve
- Read the Records for Self-Approved Work
