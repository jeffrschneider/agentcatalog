# employee-case-keeper

## take-in-a-case

Logs each concern, conduct matter and referral once, from any channel,
named or anonymous, acknowledges a concern with the date an answer is
due, and opens a restricted file or case that only the named people on
it can open, logging every opening.

covers:
- Acknowledge the Concern
- Open the Restricted Case
- Open the Restricted File
- Take in the Concern
- Take in the Conduct Matter
- Take in the Referral

## carry-the-case-to-a-decision

Records the route a named person chooses, sends a case for
investigation, sits in each hearing, each agreed plan and each appeal,
and files each check-in note with the employee's comments. Every
decision is recorded with the name of the person who made it.

covers:
- Agree the Plan
- Choose the Route
- Hear an Appeal
- Hear the Grievance
- Invite the Employee to a Hearing
- Record Each Check-In
- Send for Investigation

## set-out-the-case-history

Reads the employee's warnings still in force, gathers the record behind
a proposed dismissal, sets out the outcomes of similar past cases with
the names withheld, and sets an outcome beside them for the consistency
check. It passes on any open concern, leave or accommodation only as
the fact that it is open and its dates.

covers:
- Check for Open Matters
- Check the Outcome for Consistency
- Compare with Similar Past Cases
- Gather the Record
- Read the Employee's Live Warnings
- Set Out Similar Past Cases

## deliver-and-record-the-outcome

Sits beside the named person who sends a written answer or outcome to
the employee and the parties, records the outcome and any appeal
decision with the policy version it rests on, and checks in with the
employee on whether the actions happened.

covers:
- Check In with the Employee
- Record the Appeal Decision
- Record the Outcome
- Send the Written Answer
- Tell the Employee in Writing
- Tell the Parties the Outcome

## close-the-case

Sets the date an outcome stops counting with its reminder, closes each
case and investigation file under restricted access with its retention
date, and adds what the case showed to the debrief.

covers:
- Close the Case
- Close the Investigation File
- Record What the Case Taught
- Record What the Investigation Taught
- Set the Expiry Date
