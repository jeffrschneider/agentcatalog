# investigation-coordinator

## plan-the-investigation

Writes each allegation as a question the evidence can answer, with the
policy clause it would breach, and plans the witnesses, the records and
their order for the investigator to approve. It lists each record that
could be lost, so the HR system administrator holds it before any party
is told.

covers:
- Hold the Evidence
- Plan the Witnesses and the Evidence
- Write the Allegations as Questions

## schedule-interviews-in-confidence

Books each interview at a time and a place that keep it private, so
nobody learns who else is seen, with any companion booked where the
policy allows one.

covers:
- Schedule the Interviews in Confidence

## set-out-the-evidence

Logs every document, message, record and set of notes with its source,
builds the timeline with the evidence behind each event and each place
the accounts differ, and sets out the evidence for and against each
allegation with no finding drawn.

covers:
- Build the Timeline
- Log the Evidence
- Set Out the Evidence Against Each Allegation
