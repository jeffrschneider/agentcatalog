# feedback-keeper

## take-in-an-ask

Takes in each ask in the customer's own words with what they are trying
to get done, checks with the specialist that the product does not
already do it and that nothing is broken, and writes the need behind it
without inventing a solution.

covers:
- Check What the Product Already Does
- Take In the Request
- Write the Need Behind the Request

## match-and-count

Matches each need to the requests already logged under other words,
counts every account asking with what it pays, logs the request new or
joined for the product team, and counts the open requests each period.

covers:
- Count the Accounts Asking
- Count the Feature Requests
- Log the Request
- Match It to the Requests Already Logged

## keep-the-customer-linked

Tells each customer in the approved wording how requests are handled
with no promise and no date, puts the product team's questions to the
customer through the specialist, and marks the case with the request so
a later release reaches the customer.

covers:
- Answer Questions from the Product Team
- Mark the Case with the Request
- Tell the Customer How Requests Are Handled

## carry-a-release-back

Takes in a released request with its version and plans, lists every
account that asked with its case and whether its plan has the feature,
and records a release that misses the need in the customer's own words.

covers:
- List the Customers Who Asked
- Record a Release That Misses the Need
- Take In a Released Request

## set-out-what-customers-said

Places the period's cases, survey comments, complaints and requests
under one set of topics, puts the cases, the counts and the customers'
own words under each finding, and records each decision a reader takes
with its owner and its date.

covers:
- Group What Customers Said into Topics
- Put the Evidence under Each Finding
- Record Each Decision

## record-what-requests-taught

Records which requests were logged twice, which asks turned out to be
faults or features the product already had, how long each took to log,
and how long customers waited to hear that a request had shipped.

covers:
- Record What the Run Taught
