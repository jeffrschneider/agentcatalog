# disclosure-check

## read-the-market-rules

The agent gathers the disclosure rules in force in every market a piece
will run in, at the version the organization has adopted, and writes
down what each one requires.

covers:
- Read the Disclosure Rules

## state-the-required-wording

Before the material is made, the agent says which lines it has to carry
in each market it will run in, and gives that wording to the people who
write and produce it.

covers:
- Add the Disclosures Each Market Requires
- Brief the Creators

## score-material-against-the-rules

The agent reads a piece against the rules that apply to it and gives
every item a verdict that cites the rule and the market it comes from.
It scores a draft before it runs and it scores the sized or adapted
versions again.

covers:
- Score against the Disclosure Rules
- Score the Adapted Set
- Review the Drafts
- Check the Comparisons

## clear-material-for-sign-off

The agent puts its verdicts in front of the approval, so the named
signers see what passed, what failed, and which rule each failure came
from.

covers:
- Get Sign-Offs

## check-what-is-already-published

The agent reads material that is already live and reports anything
running without the disclosure its market requires.

covers:
- Check the Disclosure
