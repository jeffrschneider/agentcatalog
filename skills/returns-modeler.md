# returns-modeler

## take-a-first-view-of-value

Builds a value range from the seller's numbers and comparable sales and
listed companies, checks the fund's return at the low, middle and high
of the range, sketches the equity, debt and rollover each price would
need, and gives the indication of interest its range and its financing.

covers:
- Build the First View of Value
- Check the Return at Each Price
- Sketch How It Would Be Paid For
- Write the Indication of Interest

## build-the-deal-model

Takes in the agreed numbers, sets the entry price and the structure,
models the later rounds or the debt, sets the loss, low, plan and high
exit cases, computes the multiple of money and the internal rate of
return at each, tests the sensitivities, finds the breakeven, sizes the
reserve, and writes down every assumption with its source and owner.

covers:
- Compute the Return at Each Case
- Find the Breakeven
- Model the Later Rounds or the Debt
- Set the Entry Price
- Set the Exit Cases
- Set the Structure
- Size the Reserve
- Take in the Agreed Numbers
- Test the Sensitivities
- Write Down Every Assumption

## issue-the-model-and-write-its-returns

Has the deal lead agree the cases, locks and issues the model at a
version, hands it to the mandate check, the memo and the term sheet, and
writes the memo's returns and proposed terms from that version alone.

covers:
- Agree the Cases
- Hand the Model On
- Issue the Model at a Version
- Write the Proposed Terms
- Write the Returns

## price-the-negotiation

Sets the walk-away terms with the return at each, prices every ask on
the term sheet and every change in the definitive agreements that moves
value, prices the side documents the agreement relies on, and models
the agreed text once more against what the committee approved.

covers:
- Check the Final Return
- Price Each Ask
- Price the Changes That Move Value
- Set the Walk-Away Terms
- Settle the Ancillary Agreements

## model-the-options-for-a-holding

Lays out and models each option for a company in trouble with its
downside, prices the terms agreed with the other parties, models each
exit route beside the return from holding on, and sets with the deal
lead the lowest price the fund will accept.

covers:
- Agree Terms with the Other Parties
- Lay Out the Options
- Model Each Option
- Model Each Route's Return
- Set the Price the Fund Will Accept
