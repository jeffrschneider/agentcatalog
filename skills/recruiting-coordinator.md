# recruiting-coordinator

## plan-the-hire

Takes in an approved position or an internal opening, drafts the
must-haves from the approved job and checks each one for a requirement
the work does not need, turns the agreed must-haves into a structured
interview plan with a written scoring scale, checks the panel is trained
and free, sets the dates and hands the signed plan to the search.

covers:
- Check the Draft Must-Haves
- Check the Panel Is Ready
- Choose the Sources
- Confirm the Must-Haves and the Interview Plan
- Draft the Must-Haves
- Hand the Plan to the Search
- Set the Dates
- Set the Scoring Scale
- Take In the Opening
- Take in the Approved Position
- Write the Interview Plan

## run-the-posting

Lists where a posting will run, checks that every requirement it states
is a written must-have and that its wording would not put off qualified
people, publishes each approved version inside the company and in each
place the plan names, confirms applications arrive, keeps the posting
current and takes it down everywhere when the position fills.

covers:
- Check the Requirements Against the Must-Haves
- Check the Wording
- Confirm Applications Arrive
- Keep the Posting Current
- List Where the Posting Will Run
- Post It Inside the Company
- Publish the Posting
- Take in the Hiring Plan
- Take the Posting Down

## keep-the-pipeline

Logs each application and internal application with its source,
acknowledges it, withholds the details the screen does not need,
releases them only for those going forward and only to the people who
book their interviews, hands candidates from the screen to the
interviews and on to the checks and the offer, keeps on file only those
who agreed, and passes an accepted move to the record.

covers:
- Acknowledge the Application
- Hand the Candidates to the Interviews
- Hand the Chosen Candidate On
- Keep Applicants on File by Consent
- Pass the Move to the Record
- Release the Details to Those Who Need Them
- Take In Internal Applications
- Take in Each Application
- Take in the Candidates
- Withhold What the Step Does Not Need

## check-the-evidence

Prepares each interviewer's pack, collects the scorecards before anyone
sees another's scores, checks every screening note and every score for
the must-have and the evidence behind it, strikes any remark the
must-haves do not cover, and sets the scores side by side for the
debrief.

covers:
- Check Each Note
- Check Each Scorecard
- Collect the Scorecards
- Prepare the Debrief Pack
- Prepare the Interview Packs
- Run the Interviews

## record-and-answer

Records the hiring manager's decision with its reasons and the scores it
rests on, drafts a clear and courteous answer for every applicant and
candidate, sends each one once the decision is recorded, and drafts the
written internal offer the hiring manager makes.

covers:
- Answer Every Internal Applicant
- Draft the Answers
- Make the Internal Offer
- Record the Decision
- Send Every Answer
- Tell Each Candidate

## learn-from-each-hire

Closes each plan, posting, screen, interview loop and internal move with
a debrief of what it took, what each source drew, where the scores or
the sample review disagreed, and what the next one does differently.

covers:
- Record What the Loop Taught
- Record What the Move Taught
- Record What the Planning Taught
- Record What the Posting Drew
- Record What the Screen Taught
