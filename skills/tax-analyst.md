# tax-analyst

## confirm-the-rules

Reads the rates, the rules and the form for each period or year against
the last provision or return under the rules of each jurisdiction, and
asks the head of tax to confirm each change before anything is worked
out on it.

covers:
- Confirm the Rates and Rules
- Confirm the Rules for the Period
- Confirm the Rules for the Year

## gather-the-tax-records

Gathers the period's sales and purchase lines, the signed accounts and
the schedules a return needs, carries in each difference between a past
provision and its filed return, and pulls only the records an audit
request covers, holding back other periods, other entities and any
protected advice.

covers:
- Carry In the Return Differences
- Gather the Period's Transactions
- Gather the Schedules
- Hold Back What the Request Does Not Cover
- Pull the Records Asked For
- Take In the Closed Accounts

## work-out-the-tax

Works out the tax charged on sales and recoverable on purchases, the
items the tax rules treat differently from the accounts, the current and
the deferred tax in the provision, the taxable income item by item and
the tax due after credits, losses and instalments.

covers:
- Find the Differences From the Accounts
- Work Out the Current Tax
- Work Out the Deferred Tax
- Work Out the Tax Due
- Work Out the Tax on Purchases
- Work Out the Tax on Sales
- Work Out the Taxable Income

## set-out-positions

Sets out each open treatment, uncertain position, claim and election,
each option for answering a notice and each adjustment an auditor
proposes, with the facts, the support, the reading of the rule and the
tax, interest and penalty at stake, for the head of tax and the CFO to
decide.

covers:
- Assess Each Adjustment
- Set Out Each Judgment
- Set Out Each Open Treatment
- Set Out Each Position
- Set Out the Options

## reconcile-and-explain

Reconciles each return to the tax accounts in the ledger and the tax
charge to the headline rate, and sets each return and provision beside
the last one and the provision for its year, with every difference past
the tolerance explained.

covers:
- Compare With the Last Period
- Compare With the Last Return
- Compare With the Provision and the Last Return
- Reconcile the Effective Rate
- Reconcile the Return to the Ledger

## answer-the-authority

Checks a notice line by line against what was filed and paid, supplies
the figures and records for each audit answer, drafts the response in
the form the authority asks for with each figure traced, and sets out
each correction for the return's own process.

covers:
- Check the Notice Against the Return
- Correct the Return
- Draft the Answers
- Draft the Response

## hand-on-and-settle

Hands the approved provision and each return's adjustment to the ledger
for approval and posting, supplies the schedules for the tax note, and
sets out each tax payment and each settlement with the authority's
reference, its date and the account from the authority's own published
details for the named approver.

covers:
- Adjust the Provision to the Return
- Draft the Tax Note
- Hand the Provision to the Ledger
- Prepare the Payment
- Prepare the Settlement
- Record What the Provision Taught
