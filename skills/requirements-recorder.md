# requirements-recorder

## take-in-the-discovery-notes

Takes the confirmed discovery notes in as the one source the record is
written from, so what goes down is what the buyer said and not what was
hoped for.

covers:
- Hand the Notes On
- Take in the Discovery Notes

## write-each-requirement-down

Splits what must be true from what was only wanted, and writes one line
per requirement in the buyer's own words, with any paraphrase marked as
a paraphrase. Names the person who asked for each one and the date they
asked.

covers:
- Split the Needs from the Wants
- Write Each One in the Buyer's Words
- Name Who Asked for Each One

## test-the-list-with-the-buyer

Finds the pairs that cannot both be met and puts them back to the buyer
rather than settling them on the buyer's behalf. Has the buyer rank the
list, and marks the requirements that cannot be met, each with its
reason, before any shape is drawn.

covers:
- Find the Contradictions
- Ask the Follow-Up Questions
- Have the Buyer Rank the List
- Mark What Cannot Be Met

## read-back-and-version-the-record

Reads the record back to the buyer for confirmation, versions it with
the earlier versions still readable, and hands that one version to
shaping. The record does not go forward as confirmed on silence.

covers:
- Read the Record Back
- Version the Record
- Hand the Record to Shaping

## watch-what-changes-after-the-handover

Watches for the requirements that arrive after confirmation, and
versions each one in rather than absorbing it quietly. Reads the shape
back against the record line by line, showing each requirement met,
deferred or refused, and records what a trial and the run itself taught.

covers:
- Watch for Drift While Shaping
- Map the Shape to the Requirements
- Record the Result and What It Taught
- Record What Was Learned
