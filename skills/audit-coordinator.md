# audit-coordinator

## run-the-request-list

Opens the audit with its scope and last year's letter, keeps the
auditor's requests on one numbered list with an owner and a due date for
each, sends each request to whoever holds the answer, checks each answer
against the ledger and the request before it goes, and sends and logs
each approved answer.

covers:
- Check Each Answer Before It Goes
- Log the Request List
- Open the Audit
- Send Each Request to Its Owner
- Send the Answers and Log Them

## close-the-audit

Tracks each adjustment the auditor proposes for the named people who
decide it, prepares the representation letter with each statement traced
to its source, receives and files the signed opinion, drafts the answer
to each point in the auditor's letter as the controller agrees it, and
records what the audit taught.

covers:
- Agree the Response to the Auditor's Letter
- Prepare the Representation Letter
- Receive the Auditor's Opinion
- Record What the Audit Taught
- Track Each Proposed Adjustment
