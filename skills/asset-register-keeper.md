# asset-register-keeper

## record-the-assets

Opens each period's register, checks each purchase coded to an asset
class against the capitalization policy and threshold, records each new
asset with its class, cost, service date, useful life, location and
owner, asks each owner to confirm it, takes in each disposal and
transfer, and checks the register against what physically exists.

covers:
- Check Each Cost Against the Policy
- Check the Register Against What Exists
- Confirm Each Asset With Its Owner
- Open the Period's Register
- Record Each New Asset
- Take In Disposals and Transfers

## read-the-leases

Takes in each signed or changed lease with every document it names,
reads its term, its payments and its options each with the clause it
came from, asks the lease owner how the business means to use the asset
and each option, and enters the lease in the register with the decided
judgments.

covers:
- Ask the Lease Owner
- Enter the Lease in the Register
- Read the Options
- Read the Term and the Payments
- Take In the Lease

## set-out-the-judgments

Sets out each disposal and each sign of impairment, and each judgment a
lease raises, with the evidence, the carrying value or the options and
the effect of each under the accounting framework, for the controller
to decide.

covers:
- Set Out Each Disposal or Impairment
- Set Out the Judgments

## work-out-and-post

Works out each asset's depreciation and each lease's schedule of the
liability, the asset and each period's entries, posts the period's
approved changes from the register, sets each lease's later entries to
post at each close, and hands the register to the close.

covers:
- Hand the Register to the Close
- Post the Register to the Ledger
- Record What the Lease Taught
- Record What the Period Taught
- Set the Period Entries to Post
- Work Out the Depreciation
- Work Out the Schedule
