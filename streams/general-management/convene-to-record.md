# Value stream: Convene-to-Record

`vs/gm/convene-to-record v1`

**position:** 1
Some work is too wide for one agent, and the answer is a conversation:
several agents in one room, working a declared pattern, moving through
an agenda, leaving a record. A run starts when somebody needs more than
one agent on a question - a document that wants critique before it
ships, a decision that wants options argued, a plan that wants building
in stages. The processes here choose the collaboration pattern and the
agenda, convene the members with their roles, run the session phase by
phase with a facilitator moving it, and close it when the agenda is
exhausted rather than when the talking stops. Every run ends the same
way: what was made goes to whoever asked, and the record holds who said
what, which phases the work moved through, and who moved it. The work
done inside each phase belongs to the departments that own it; this
stream owns the running of the session itself.
