# Value stream: Rule-to-Route

`vs/rev/rule-to-route v1`

**position:** 4
A run starts when the organization decides who should get what, and how
quickly. The processes here write the routing rules, implement them in the
systems that deliver work, set and publish the response clock, watch what
actually happens against it, and change the rules when the answer is
consistently wrong. The stream owns the rule and the measurement rather than
the conversation: whether an inquiry was any good is the judgment of whoever
received it. Every rule here is readable by the people it routes to, because
a routing rule nobody can see is indistinguishable from an accident.
