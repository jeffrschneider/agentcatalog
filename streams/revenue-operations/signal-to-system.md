# Value stream: Signal-to-System

`vs/rev/signal-to-system v1`

**position:** 1
A run starts when the revenue organization needs something its tools cannot
do, or when a tool it has stops earning its place. The processes here work
out what is actually needed, evaluate what exists, run the security and
procurement review, integrate the choice with the systems on either side of
it, administer it once it is in, and retire whatever it replaced. Nothing
here decides how the work is done, only what it is done inside. A tool
bought without a process to run in it is the failure this stream exists to
prevent, which is why every run names the process it serves.
